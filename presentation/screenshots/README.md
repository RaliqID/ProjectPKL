# Screenshot — SAKHA Finance Operations

Tangkapan layar aplikasi **SAKHA Finance Operations** (Sistem Informasi Pengelolaan
Data dan Dokumen Finance) untuk keperluan laporan & presentasi PKL.

> Prototype berdasarkan kegiatan PKL di PT. Sakha Internasional. Data bersifat contoh
> (fiktif), bukan data perusahaan.

Diambil pada resolusi **1440×900**, akun `admin@sakha.test`.
